# Naming research

Research date: **2026-09-18**

**Anchor remains the current code name, and Flow remains the repository name.** This research does not rename the project. **Flow State** is a provisional beta candidate; **Lock in** is a possible focus-session action label.

## Findings

Both names already appear prominently in nearby productivity products. Flow State fits a calm assistant for reducing overwhelm, but its closest existing products overlap substantially with this app. Lock In appears across several focus and habit apps, making it difficult to distinguish in search.

| Candidate | Current iOS App Store examples | Relevant overlap |
| --- | --- | --- |
| Flow State | [FlowState: ADHD Focus & Tasks](https://apps.apple.com/us/app/flowstate-adhd-focus-tasks/id6766418779); [FlowState: Focus Timer](https://apps.apple.com/us/app/flowstate-focus-timer/id6761791063) | The first listing advertises energy-based tasks, calendar integration, and brain dumps converted into actions. The second is another close name in the focus category. |
| Lock In | [Lock In: Focus Timer & Blocker](https://apps.apple.com/us/app/lock-in-focus-timer-blocker/id6744293692); [Lock In: Habit Tracker](https://apps.apple.com/us/app/lock-in-habit-tracker/id6781959120) | Existing apps use the exact phrase as their leading name for focus, project organization, habits, and goals. |

Broader web searches also surface directly related products: [Flow State](https://myflowstate.ai/landing) markets a personalized AI operating system, while [Lock In](https://www.lockedtf.in/welcome) markets voice-first AI scheduling. These are product claims from their own sites, not independently tested capabilities.

## Recommendation and limits

Keep **Flow State** provisional for beta discussion and consider **Lock in** for the focus action. Neither plain name currently provides strong differentiation for a public planning, focus, and voice-capture app. A distinct public brand would likely be easier to find and recommend; that is an inference from the overlapping listings, not a measured search-ranking result.

This is a bounded market-name and search-confusion check using public US App Store listings and primary product sites. It is not trademark clearance, a legal opinion, or confirmation of App Store name reservation, domain availability, or availability in every region. No alternative brand has been cleared or recommended here.
